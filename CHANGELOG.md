# Changelog

## 0.1.0 - 2026-11-03

- Initial standalone JavaScript reference library for percentages, compound interest, length, speed, temperature and Mach conversion.
- Added exact nautical-mile factors, worked unit-conversion examples and explicit Mach assumptions.
- Included a directory of related live Calxo calculators and converters.
- Added input validation, automated tests, a Node.js 22/24 CI workflow, contribution guidance and MIT licensing.
