# Speed conversion demonstration

Open `index.html` in a modern browser. No build, dependencies, analytics or network calls are needed for the calculation. The visible reference link opens Calxo's matching interactive tool.

The example supports non-negative finite speed magnitudes, fractional inputs, reverse conversion from the unrounded calculation, visible unit cancellation and display rounding. It distinguishes average speed from peak speed. Unit definitions: [NIST conversion factors](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors).
