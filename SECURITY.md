# Security policy

This repository contains standalone calculation utilities and does not require credentials, network access, or production services.

Please do not report security issues in a public issue. Contact the maintainers through GitHub's private vulnerability reporting feature when available, or use the contact details on [Calxo.ai](https://calxo.ai/contact). Include the affected file, steps to reproduce, and the impact. Do not include real secrets or personal data in a report.

Supported versions: the latest release on the default branch. Security reports will be reviewed as promptly as possible; no response-time guarantee is made.
