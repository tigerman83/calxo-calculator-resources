# Contributing

Thanks for helping improve these calculation references.

- Keep implementations independent of Calxo.ai's private production application.
- Include the formula, input domain, units, assumptions, and limitations for every new calculation.
- Add tests for an ordinary case, boundary values, and invalid inputs.
- Avoid rounding intermediate results; document any deliberate precision rule.
- Run `npm run check` and `npm test` from `javascript/` before submitting a pull request.
- Do not include credentials, private data, production configuration, or code copied from another project without permission and compatible licensing.

For formula changes, cite a reliable reference where applicable and explain the effect on existing behavior.
